The timeout card shows Figma's title and body, full red outline and tinted surface, warning icon, and responsive action order. No single-side accent border appears. Other structured failures keep their specific body and code; their diagnostic tags and raw detail remain behind the disclosure. The disclosure opened in the disposable package. “Pick another model” opens the chat model picker on desktop and the [current mobile model sheet](CHAT_MODEL_PICKER_CURRENT_REVISION.md). “Try again” is wired to the existing send path for an eligible plain-text prompt and targets only its conversation. It was not clicked, to avoid a real model request. The illustrative API-fallback toast was not generated by the synthetic timeout.

TypeScript, Electron Vite, disposable Windows packaging, and the desktop regression passed (**54 files / 400 tests**). The disposable package had no renderer error or document overflow at the four measured widths. This is scoped visual and interaction evidence, not a live provider timeout or retry acceptance. The Windows title bar and five-tab mobile navigation still differ from the iPhone frame; the Kibble placement decision remains open.
