# Desktop Dark Tools status — canonical review

**Authority:** [Kel Design System, FINAL Tools `188:1956`](https://www.figma.com/design/BlpVvZGuc9j9HhxUojIiJI/Kel-Design-System?node-id=188-1956), plus Foundations and Components. **Rendered evidence:** [r47 at 1440px](key/r47-tools-1440.png), [r47 at 800px](key/r47-tools-800.png), [measurements](r47-desktop-check.json), and [interaction check](r47-tools-interactions.json).

The r47 source changed MCP rows from 50px to the FINAL 40px desktop rhythm. The first row shows a connected check, and both rows retain their expand and retest controls. At 800px, each row grows to 48px for its label and the card keeps Add MCP inside its bounds. The functional Add MCP control and the second row's status detail are extra runtime information absent from FINAL's sample. They do not justify removing live controls. The r47 interaction record confirms expand/collapse, Add MCP menu, and navigation to Model.

No `ToolsSettings` source changed between r47 and canonical `main`. The r47 packaged captures therefore remain evidence for this scoped layout and connected sample state. No new source repair was indicated by this comparison. The canonical App was not relaunched for this review.

**Canonical installed-app follow-up (2026-09-24):** `App` at source `842c01d` ran with a disposable data root and no live credentials. The [fresh 1440px](key/canonical-tools-1440.png) and [800px](key/canonical-tools-800.png) captures show both built-in MCPs as **Not tested**. There were no page errors or document overflow. A loopback HTTP MCP named `local-audit-mcp` returned 503 after 4.5 seconds. The [active retest](key/canonical-tools-retest-1440.png) showed **Checking**. The [failed 1440px](key/canonical-tools-error-1440.png) and [800px](key/canonical-tools-error-800.png) captures showed **Needs setup**, Report Issue, and the status detail. The app and local server stopped, and the disposable root was removed. No request used the live `Data` root.

**Confirmed design gap:** the failed-status detail uses Arco's near-black popover. Components `156:159` specifies a frosted ice-glass tooltip with light text and a continuous outline. The failed-state capture also places this large detail above the row, covering the Tools heading and card title. The 800px failure row fits within the viewport but wraps its MCP name and Report Issue label. The short Figma tooltip is not a literal layout for this longer diagnostic, so adapt its material and edge without discarding the diagnostic text or controls.

**Source repair:** the status popover now carries a scoped class and uses the Components ice-glass gradient, light text, and neutral outline. Desktop typecheck and 45 files / 298 unit tests pass. This source build has **not** been packaged or visually rechecked, so the pictured black popover remains the installed-app result.

**Still open:** recheck the repaired status detail at 1440 and 800px. Exercise an enabled Image Model with an isolated model configuration. Keyboard and assistive-technology checks remain open. The connected r47 capture is still separate evidence; this run did not connect a real MCP.
